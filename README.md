# AWS EC2 Web Server Deployment and Monitoring

## Project Overview

This project demonstrates the deployment and management of an Amazon EC2 instance using AWS Academy.

A Linux-based EC2 instance was launched and configured to host a simple web application using a web server. The project also covers security group configuration, CloudWatch monitoring, instance configuration changes and resource sizing.

## AWS Services and Technologies

- Amazon EC2
- Amazon CloudWatch
- AWS Security Groups
- Linux
- HTTP and SSH
- AWS Management Console

## Implementation

### 1. Launch an EC2 Instance

Launched a Linux-based EC2 instance and configured it to host a simple web application.

### 2. Configure Security Groups

Configured inbound traffic rules to allow HTTP access and restrict SSH access to a specific IP address.

### 3. Monitor Instance Performance

Reviewed CloudWatch metrics, including CPU utilisation and network activity, to understand instance performance and health.

### 4. Modify Instance Configuration

Reviewed and modified instance configuration to support changing workload requirements and improve operational safety.

### 5. Review Instance Sizing and Service Limits

Reviewed EC2 sizing and service limits to understand the relationship between resource allocation, cost and performance.

## Key Learning Outcomes

- Understanding virtual servers and EC2 deployment.
- Hosting a basic web application on Linux.
- Managing inbound and outbound network access.
- Using security groups as virtual firewalls.
- Monitoring instance performance with CloudWatch.
- Understanding instance sizing and termination protection.
- Balancing cloud resource costs and performance.
